# 阴宅：地形形势、墓位关系与取法比较

适用于墓地、陵园、祖墓环境、历史墓园及骨灰安置空间的传统风水解读。用户只问原理、典籍或已有案例时直接查资料，无需照片；用户要求看图时先分析真实可见的地形和墓体关系，再按宿主图像工具实际标注。阴宅报告不套床、灶、客厅或商铺收银栏目。

本模块直接选读《葬书》四库本、《撼龙经》及《疑龙经·上篇》的包内网页转录，分别保存版本、段首和实际范围于[书籍研读记录](book-reading-yin.json)。现代方法资料及既有译述复核见[来源核查](yin-sources.json)。所读古书并非已校勘足本；下述观察流程是本技能的运用约定，传统人事断语不作效验事实。

另选读《雪心赋》个人网站录文的形局、水法、龙脉、龙虎和穴法相关节，未校其底本；1505年国图藏《地理雪心赋句解》仅核版本与许可，影印正文未读，两者不混称同一本。该录文补充的判断是：直出之水还要看外层是否回转横拦，左右强弱还要看对评估点的围护或逼近，不能孤立取一条形名。实际范围及原链接见[书籍来源核查](book-source-checks.md)，不用此录文作精确分金或后代效验依据。

## 一、先定对象、观察点与前后

先分丘陵墓地、平洋墓地、陵园排墓、历史墓园、骨灰龛位或尚未建成的候选地。祠堂、祭堂或牌位空间是建筑使用对象，不能只因与祭祖有关就当成有地下棺葬的墓穴；龛位也不能套成整片山地的龙穴水局。

指定本次参照点P及所用向外观察轴A：例如“以墓前平台中央为观察点，沿已知碑面向外看”。只有碑正面照片时，先用画面左右描述；相机视线可能与墓向相反，不据照片左右直接分龙虎。若P、A只是临时分析约定，应直说，不冒称已测得穴心或真向。

## 二、把龙、穴、砂、水、向读成一组关系

| 对象 | 传统概念及本轮读书所得 | 当前分析应落实到什么 |
|---|---|---|
| 龙与势 | 《葬书》以远势、近形分层；《撼龙经》既论高山星峰，也专论平洋两旁水势与环绕；《疑龙经》提醒漂亮星峰可能只是枝叶护从 | 描述山脊、坡面、支脉与两侧沟谷的可见连续关系。一个高峰、树冠或远景轮廓不足以定入首来龙；平地无高山也不能直接判无龙 |
| 穴与止 | 所读《葬书》重来势与止聚相接，不能只有远山而无近处承接 | 将已有墓位或候选落位放回近坡、台地、前后护持比较。照片可以讨论落位的相对关系，不能由一个凹点或草色直接点出唯一穴位 |
| 砂与护 | 四势按立穴处的前后左右解释；古注强调两侧婉顺、围护，且辨“龙昂虎伏”传习问题 | 看左右形体是否向评估点回顾、开合或逼近，不以“左边一定高、右边一定低”代替完整判断；自然山体、人工挡墙和成排墓碑分别记录 |
| 明堂与朝应 | 《疑龙经》把明堂与朝水、朝山及关局连看，并警惕把山水围合的关峡误认为穴前明堂 | 指定哪一片是墓前承接空间、边界何在、与墓位怎样相接。大空地不自动为佳；近案、远朝须以真实前后、距离与视点说明，不按画面上、下命名 |
| 水与水口 | 古书关心来去水、会合与局口；不同近现代法门对人工口的地位有分歧 | 将自然溪河、季节沟渠、积水、陵园排水沟、人工出水孔分项记录。说明“哪一层水系的哪个出口”，不把一个管孔自动叫全局水口 |
| 向与理气 | 方位判断须有明确测量对象和所选法门 | 碑面朝外、墓体主轴、已知棺/骨灰安置轴、道路走向、相机方向及入首来龙方位分别记；不能默认彼此重合 |

这些关系共同决定总评：例如后方有承接、两侧适度围护、前区能够展开且水路去向可核，可以描述为“本次所见形成前后相接、左右收束的形势”；若只见碑与铺地，则只完成近局判断，不补出整条来龙或天然水口。

## 三、读书后形成的六项具体判断条件

### YIN-R1　高山与平洋分别看，不以高大取代整体

《撼龙经》开篇同时讲高山与平地，平洋段转看水势、微起伏与外围环绕；《葬书》古注也论平洋低阜及外卫。因此分析平地墓园时，可比较微地形、沟谷、前场和外围形体的组织，不能因没有高山便结束判断。反过来，背后高峰显著也不证明近墓处已得到承接，仍须看坡势是否到此缓下、墓位与周围怎样连接。

这不是从普通照片识别地下“龙脉”的能力声明。植被遮挡、人工堆填或护坡使原地形不清时，只记录可见形态与改造痕迹。

### YIN-R2　龙虎论形态与相向关系，先校观察方向

所读《葬书》古注以立穴处解释四兽，并把龙虎的婉顺、回护与反翘、逼迫相比较，还提醒“龙昂虎伏”的俗传有误读。可取的是两侧形体对本次评估点怎样开合，不能压成通用左右高度不等式。拍照位置在墓前或墓后、图像镜像都会改变画面左右，先核观察点再使用龙虎名词。[四库本相应段](classics/03-zangshu-siku.txt)

若一侧近且陡、另一侧低且远，可以给出“围护不对称”的局部比较，再看前方是否仍有承接与外层护持；不从一张照片断某一房、某一性别或后人的命运。

### YIN-R3　明堂不是所有空地，案朝不是所有好看山峰

《疑龙经·上篇》反复区分枝干、护关与结作，说明山峰秀丽、四周围合仍可能处于行进或关峡关系，而非所评墓位的明堂。实际报告要说明前场从哪里开始、向哪里开、两侧如何接、前山是否朝向该点。不能只因照片正中有空地就命名“聚气明堂”，也不能以最高最尖峰自动作朝山。[上篇所读段](classics/05-yilongjing-shang.txt)

可先保留已有自然开敞与围护，不为凑案山而堆石立物；近前遮挡是否需要处理，要比较它真实挡到什么、是否属他人或公共区域。

### YIN-R4　天然水口、墓前小水与排水设施分层

先核水体类别、实见流向、汇流位置、出口与墓位关系，再选具体水法。静态照片可以看到沟与水面，未必看得到来去水，也不能证明全年水量和地下水情况。人工排水是否畅通是可观察的现场问题，传统收放水解释则归所选法门，两者不互相代证。

Joey Yap的阴宅教学强调实地地形与内外水，且把某些墓旁沟孔视为排水设施；现有ROUND2-004译述则在特定SYYG体系中使用人工出水口。两者体现对象/法门差异，不能写成“所有管孔都算水口”或“人工口绝不能入任何水法”。目前没有统一校验两套算法。[教学原文](https://www.joeyyap.com/tutorial/tutorial-details.asp?tid=501)；[既有译述](https://www.loktinfengshui.com.au/yin-feng-shui-case-study-from-china-provided-by-a-feng-shui-fellow-student/)

### YIN-R5　碑向、墓轴与来龙各用自己的字段

碑面若能辨认，可以说明其朝外法线是一个候选测量对象；这不代表已知其角度，更不代表知道地下安置轴。来龙的入首方向也不能用碑轴反向代替。测量需注明对象、测点、前视/回视约定、磁北/真北基准、数值与误差；误差跨分界时保留范围，不硬定兼向、分金或合局。

既有ROUND2-004的网页标题称Geng Facing，英文正文却称墓坐Geng，中文原文附在未查看图片中。因此本次将其视作坐/向未定的译述，不自行倒转、纠字或据之排盘。这一纠错不增加案例数。

### YIN-R6　古书形势分类不能直接代替地质与修墓处方

《葬书》谈童、断、石、过、独时，所存古注逐项讨论类似形体的例外。由此可学到分类需看整体关系，不能只见裸岩、孤峰或切坡即贴一个名称完成判断。古书对土色、湿润、深浅及葬法的说法属于该传统语境，不据照片换算挖深、填土、截水或开井尺寸。

可见的裂缝、冲刷、积水和倾斜应按实际位置记录，先比较照片拍摄畸变、表面变化与现场现象，再由管理和相关专业人员核实成因。传统形名不能证明结构或水文状态，也不构成自行改碑、迁葬或改变水路的指令。

## 四、不同资料条件下怎样开始

| 当前资料 | 现在可以形成的内容 | 哪一部分仍需补足 |
|---|---|---|
| 一张碑与近地正面照 | 墓体、近前平台、邻近挡墙/植被的可见关系；拍摄视点与遮挡 | 墓后、两侧全貌、真实轴线、外层水系及远势 |
| 墓前向外全景或数个固定视点 | 前场开合、近案远景、两侧护持的有范围比较；多图是否同一位置需先核 | 图片拼接、比例、高差与来去水，不能据照片补角度 |
| 有北箭头与比例的地形/总平面 | 图载地形、沟谷、墓位与外围关系；注明图件精度与年代 | 现场变化、遮挡、季节水情及实测向首 |
| 已有可靠坐向、地形和明确法门 | 解释所给盘或取法的输入及条件，逐项比较形势与理气意见 | 包内没有自动阴宅分金/水法引擎，不能声称已运行；未核算法另查 |
| 骨灰龛位照片 | 建筑/排位、可见前区与使用环境；按该法明确评估尺度 | 不自动继承山地棺葬的龙穴、水口或安置轴条件 |

缺资料时先交付能成立的局部判断，然后只列会改变下一步结论的少量资料；不以出生信息、精确地址或家族疾病作为通用起步条件。需补外景时，优先请提供可公开的地形图、非识别性视角或已有测量，避免索要墓碑姓名和个人信息。

## 五、阴宅专用报告与标注

正文以“整体形势—决定性关系—取法与分歧—保留/核查次序”连贯论证，篇幅随资料调整。建议使用下列相关部分，不强凑全部栏目：

1. **对象与总评**：是近墓局部、陵园分区还是完整地形；说明观察点、向外基准和本次最重要的形势判断。
2. **来势与近形**：所见山脊、坡面、台地怎样相接；哪些是自然形体、哪些可能人工改变。
3. **砂护、明堂与朝应**：围护与开敞如何配合，前场和墓位是否有实际承接；视角不明时用画面定位，不强叫龙虎。
4. **水系与向轴**：自然水路、排水设施、已知流向和口位分别说明；碑向、墓轴与来龙分开记录。只有合格输入才展开指定理气法。
5. **方案与取舍**：先说宜保留的关系，再列清理可移动杂物、补充现场观察、核查设施等动作的对象和目的；工程或安置变更只列待核条件，不从本图发施工决定。
6. **关键缺项与来源**：集中列会改变判断的信息；引用到实际读过的书段或原案，并标明意译、教学、自述或回访性质。

用户要求图片标注时，实际在原图上标观察点/视线（只有已知时）、可见前场边界、山体/挡墙/水路、保留项和待核项；照片原有物体保持不变。未知来龙、水口、棺位和坐向不绘成确定线，不能凭空叠罗盘、穴点、分金或“后代吉凶”箭头。图中若有可识别姓名、编号或住址，不为分析而扩大展示。
