# 专业风水布局报告写作规范

适用于实景照片、户型图及外观图的中文报告。目标是让读者明白“格局如何判断、依据是什么、如何安排、为什么这样安排”，并能实际执行。篇幅随图像信息量调整；专业程度由判断和取舍体现。

阳宅按本篇及[阳宅专题](yangzhai.md)论居住、工作与经营空间；阴宅按[阴宅专题](yinzhai.md)的专用结构论地形与墓区，不套用床、灶、收银和室内主位的段落。

照片分析默认同时交付 [实际笔画标注图](photo-annotation.md)。报告沿用图中编号，让每个编号对应可见位置、判断和动作；图像与文字不能互相替代。用户只要文字时可不制图，工具未能处理时须如实说明未完成部分。

## 从单项观察形成整体判断

先确定评估对象与方法：整宅、单间、座位或外部环境；形势观察还是输入充分的某一理气方法。无坐向的单间照片仍可作局部形势报告，不能称完整勘宅。

需要贯通外局、内局与多法比较时，用[整体研判流程](layout-assessment.md)把对象、尺度、形势、取法与方案连起来；专业报告的总评须由此主线组织。

总评须回答：空间的主要组织是什么，哪一部分形成稳定的使用核心，开口与通行怎样围绕它，当前最重要的处理方向是什么。至少让两项相互关联的画面依据支持总评。例如：座位背后实体界面与前方活动空间共同支持保留会客区；门扇与临时家具的使用关系可能要求先理顺路线。不要由整洁、豪华、颜色或“看起来舒服”直接推出全宅吉凶。

接着只展开当前图真正涉及的关系：

- **主位与辅位**：先说明本次把哪一组座位、床或工作位置视为主要使用核心。这是报告的分析约定；日常谁坐、谁是“主人”未给出时不补造。比较背后实体/开口/通路、面前可用空间与相邻功能。
- **围合与开敞**：墙和家具是否围成稳定使用区，是否仍留出出入、转身和视线。围合不等于塞满，开敞不等于越空越好；必须结合实际路线与活动需要作取舍。
- **门窗与动线**：区分开口本身、人的行走路线、可见视线和待测空气流动。门窗在画面重叠不证明同轴或穿堂。多门用途、门扇和家具展开状态不明时，给条件式路线判断。
- **明暗、虚实与反射**：描述图中可见的明暗/实体/透明开口关系，讨论遮光、私密和使用感受。拍摄曝光不能证明全年采光，镜面图像不能补成实际房间。镜子有无干扰，须核它反射什么及从何处观看。
- **比例与轻重**：在可可靠比较的画面范围内，判断主要家具和辅助家具是否争占使用空间。没有尺寸不编净宽，透视畸变明显时不凭像素定比例；不按颜色、材质五行的数量判定吉凶。

把各主题连回总评。例如镜面和大窗都扩大视觉开敞时，可讨论如何让会客区仍有稳定界面；不能分别机械写成镜子一条、窗户一条，却没有整体方案。

## 术语写得准确且易懂

传统概念用于现代家具布局时明确说明室内类比，不假称古籍原句或统一流派定论。首次出现即解释，不连续堆叠未经定义的术语。

| 可用说法 | 通俗解释与使用条件 | 不由此推出 |
|---|---|---|
| 坐实向虚、背后有靠 | 作为室内类比，座位/床头背后有相对稳定的实体界面，面前留有适合该用途的空间；先核实际位置 | 贵人、事业、身体安全或结构可靠 |
| 明堂 | 用于室内时指主要坐席前可用的开敞区，是尺度转换的类比；不等于整宅中心或财位 | 空白必吉、茶几必凶、财运必旺 |
| 纳气、气口 | 标明按通行阳宅观念讨论门窗开口及内外连接；人的路线、视线、实际风感分别描述 | 已测得气场、能量流速；每扇窗均为某流派纳气向首 |
| 虚实、动静 | 本报告对实体背靠/透明开口、通行活动/停留休息关系的概括；具体到对象与使用条件 | 人格、家庭成员强弱、疾病或财富 |
| 冲、压、反射扰动 | 先指明真实可见的轴线、凸出构件或镜面反射，并说明观察范围；缺条件用“待核” | 已构成某煞、必然应灾或应验时间 |

龙虎须先确定朝向与观察基点；图片左边不能直接叫青龙方。财位、文昌位、八宅及飞星须遵守 [流派输入](schools-and-inputs.md)。专业报告可以得出“不作此项定位”，不靠补盘显得完整。

## 有论证的段落

推荐每个主题按下列逻辑写成相邻句段，按需要合并，不把标签逐句复读给用户：

1. **落判断**：在什么范围内，哪一关系成立或仍待核。
2. **给依据**：定位到图中墙、门、座位、开口等，不只是“按风水认为”。
3. **解释关系**：用明确方法/室内类比说明其意义，再说明可观察的使用影响；传统解释和实用判断不混成已证因果。
4. **作取舍**：给保留或调整的理由与条件。若改某物会牺牲通行、采光、另一用途或已有合理格局，要把代价说清。

例如，不止写“沙发靠墙，建议保留”；可写“本次以这组沙发为会客主位。两段靠背后有墙面，而活动区留在坐席前，因此可保留现有围合；若再向中央加柜或屏风，会压缩起身与绕行空间，现阶段先整理边缘路线更合适。”实际使用此类句子时必须与当前图一致。

## 提交能执行的布局方案

方案交代对象、动作、相对位置/试摆方法、要改善的关系与复核方式。依判断区分：

- **保留项**：当前已合理的主布局，以及保留后需要维持的条件。
- **优先调整项**：先做对使用和布局影响明确、代价较低的动作；如将门边可移动物品移出实际门扇与必经路，再检查完整开启与绕行。
- **条件调整项**：只在反光、风感、隐私或家具冲突确实发生时实施；给触发条件与复核方法，不能把每种可能都写成已发生问题。
- **待资料/现场核实项**：说明新增什么信息会改变哪一判断；不能把未测尺寸变成精确摆位或施工指令。

有多种方案时说明优先方案及代价，不泛泛列一串都可考虑的选项。没有明显问题可以保留大部分布局；不为了报告显得专业而造煞或推荐法器、鱼缸、屏风。

## 成文与复核

开头给结论与方法范围；正文按关键关系写连贯论证；末尾集中列方案次序与真正影响判断的缺项。自然段和简明的执行列表优先，表格用于比较，不以整篇物件表代替判断。不要反复声明无方位、非预测等相同限制；首次简短说明并在相关结论处保持边界即可。

交付前核对：总评是否有相互关联的证据；术语是否解释且取法明确；是否讲清保留和调整的取舍；行动是否可执行并保留功能；不确定性是否落到具体结论；读者是否能不查术语表就理解。不要用玄学辞藻、长篇免责声明或虚假的分数替代以上内容。

## 外局、商业与方法分歧的论证

外局结论落到“哪个物体—多远—从哪个楼层的哪个开口看—真实指向哪里”，避免只列形名。坡地把落位、标高、前庭和到达一起比较；斜顶先看可用净高，不把吊平顶当默认答案。

商业报告说明人的交易或工作序列，再比较传统取法：桌位和共享路线、收银位置与人朝向、顾客与卸货、旧楼与扩建部分分别说明。若多个方法意见不同，使用[方法比较](cases/method-comparison.md)先辨对象、输入和时间层；把当前共同可做的动作与依赖未核资料的解释分别讲清。专项已有记载见[外局](cases/exterior-knowledge.md)和[商业](cases/commercial-knowledge.md)。
