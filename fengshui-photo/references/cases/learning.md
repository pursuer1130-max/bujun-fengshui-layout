# 从公开案例改进看图分析

本轮实际数量见 [统计](stats.json) 与 [索引](index.md)。案例仅保存来源与原创短笔记，区分作者主张、可观察条件及未知；不把营销见证视为效果验证。研究建筑图单列视觉参照，不拿普通户型或九宫数据点补足风水案例目标。

## 两项具体功能规则

### E-CONVERTIBLE-CLEARANCE：检查可变家具的两种状态

相关案例：MORE-006（办公兼客房）。

看到沙发床、折叠桌、抽拉收纳、可移动隔断时，分别考虑收起与使用状态的占地、门扇、椅后移动和通行路线。当前照片只有收起状态，不能写成“展开后也畅通”；先记录缺失的展开尺寸或请用户现场试放。方案不能在改善书桌视线时妨碍客床展开，也不能让新屏风挡住抽屉或必经路线。

可用条件式建议：“若沙发床展开后会碰到书桌，可先试移轻便桌或调整工作区；是否放得下仍需实际展开核对。”不从照片像素编厘米，也不把家具状态变化称为改善运势的原因。

### E-ENTRANCE-ROLE：区分多门空间的实际用途

相关案例：MORE-002（三入口餐馆）、MORE-003（餐馆门向调整叙述）。

先标出顾客入口、送货门、内部连接门和应急出口，未知用途就保持未知。沿实际到店、迎宾、排队、收银和后勤路线检查，不以门最大、朝街、招牌或照片正面自动选当前主入口。商户可能变更门的用途，历史案例的称呼也可能过期。

先考虑接待可见性与顾客/送货路线是否交叉；作者的改门、旋转门扇、水景或飞星数值不能直接复制。实际承担疏散的门仍需保留及现场核实，不因传统纳气偏好封堵它。未知顾客入口时可以分析已见路线，但不定主入口取向或整栋建筑向首。

## 第二批研读增加的判断条件

本批14条新记录中，11条有可用的具体布局关系，3条已读客户故事因没有公开具体位置而暂缓计数。楼梯两例已实际看过配图，分辨率分别为225×300和220×199；只支持台阶与平台的粗略关系。下列规则是本项目结合案例建立的工作条件，不是从案例效果推导的吉凶定律。

| 规则ID | 使用条件与动作 | 记录锚点 |
|---|---|---|
| E-AVAILABLE-BOUNDARY | 办公室、分租房或共享空间先确认当前可用边界与权限；整栋外轮廓、租用范围和单个房间分开记录。相邻区域不属于本使用者，不等于一张局部照片证明全宅“缺角” | ROUND2-010 |
| E-COMPASS-REFERENCE | 来源使用罗盘或地图时，记录磁北/真北基准、测点、重复读数及误差；接近流派分界而误差未明，暂不硬归山向。不从案例推成所有流派必须使用同一基准；不根据室内照片补角度 | ROUND2-009；001仅作已读流程线索、暂缓布局计数 |
| E-STAIR-FUNCTION | 区分室内楼梯与建筑外阶，检查实际高差、平台、门扇、行人路线及排水条件；照片中的宽台阶和侧转台阶只作关系比较。不把“直泄气”改写成火灾因果，也不据照片改建台阶 | ROUND2-007、ROUND2-008（原配图已看） |
| E-TRADITION-FUNCTION | 给出家具朝向偏好时，同步比较门口必经路线与实际使用；朝向偏好不能覆盖已经可见的通行冲突。先用可撤回的试摆比较，不为追某一命卦方向堵门 | ROUND2-012 |
| E-PROPOSAL-STATUS | 把题主问题、网友建议、已施工及实际回访分别记录。三套备选床位仍是同一卧室，论坛“可以隔墙”也不代表经过结构或通行核验。不能把未实施的建议说成成功改造 | ROUND2-CN-001、ROUND2-CN-002 |
| E-CASE-SPECIFICITY | 实际读到客户故事仍不一定有足够布局细节。只有“分24区”“摆灯或水景”“调整床灶”，未公开相对位置、明确区位或可读图证时，先暂缓布局案例计数；不由读者补位置 | ROUND2-001、002、003（held_out） |

阴宅水口的译述实践ROUND2-004单列为阴宅取法，不能挪作室内门窗、卫生间或镜面规则。空间尺度、作者到场与转述角色均须保留。

## 学术汇总的用途

Chan与Ma的 [2024年论文](https://ijesp.iikii.com.sg/4/1/15123) 报告327住宅，但本包未取得其逐案资料，计入案例目标为0。论文可提供中性观察目录：客厅形状、前阳台、入口在选定立面中的相对位置、厨房是否独立、灶位置、厕门与房门、前后视线、房门相对、卧室子空间、厨房门与房门。它们是记录项，不能改成十条一律吉凶的评分。

这项研究的待售/在住比较不证明房屋一定易售，更不证明财运或健康因果。其宅向定义属于该研究约定，不代替其他流派的坐向测量；正文灶位文字还存在表述差异，未核清不能写入算法。

## 用案例帮助当前用户

1. 先看当前图，独立写出对象、关系和缺项，再找最多几个同类记录。
2. 每个候选比较场景、空间尺度、当前门用途、家具状态、方位/年代资料；关键条件不同就不套用。
3. 只搬回可用的判断条件与低成本动作。当前图证据不足时，案例不能代替缺失信息。
4. 引用时给案例ID和原来源，标清文字研读还是图片已看。本文支持快速路由，精确细节仍查 [原创记录](cases.jsonl)。
5. 只有实际新增、去重并完成逐案笔记后才更新数量。脚本是审计工具，不能把模板填充的记录变成真正学习。
