# 整体研判与格局论证

用于完整布局论证、方案比较及“按风水师角度分析”的请求。将形势、空间关系、理气方法和调整次序连成一条主线，按实际资料取其可做部分。以下次序是本技能的工作约定，不能冒充各派一致的祖传法诀。

## 一、定对象与尺度：先说明是在论哪一个局

整片地形、楼盘、整栋、独立住宅、房间、座位是不同层次。先用一句话锁定对象，再写与它直接相关的外部条件；一张客厅照可论会客区，不能据此判整宅的来龙、水口和宅运。边界未明时，不急于定位中心或宫位。

本地《葬书》有“千尺为势，百尺为形”“势来形止”等文句，原文及古注论山川相墓，体现远近尺度之别，并非现代房屋的距离标准。这里借其提醒先看整体环境再落到局部，属于工作方法的现代类比，不把古文的尺数换成家具尺寸。[四库本网页转录及版本说明](classics/03-zangshu-siku.txt)

## 二、审外局：看承接与围护，再辨具体冲射

外局应回答三件事：环境从何处接近建筑，主要开口面前有什么空间，周边高低与遮挡怎样围护或逼近。将道路、地形、邻楼和实际入口连起来，先描述向背、远近、高低、开合，再解释所选传统形势概念。

“有情、环抱、反背、直冲”必须有对象与观察基点：哪一段道路或岸线，围向哪个建筑立面，是否在真实开口的视线中。弯路不能仅因弯曲便称玉带，直路也不能只凭远景投影定为路冲。邻楼角的结论要落到实际楼层和目标开口；总平面中的线条关系不足以代判整栋。

传统龙、穴、砂、水用于自然地形时，分别涉及山脉来势、选定落点、周边形体和水系；城市室内的门路、走廊、鱼缸不能未经说明就取代这些对象。龙虎还要交代立足点与向首，不能把画面左、右固定叫作青龙、白虎。专项依据见[外局知识](cases/exterior-knowledge.md)及[流派输入](schools-and-inputs.md)。

## 三、辨内局：沿一条主线看聚散、动静与主次

先选决定布局的关系链，而后讨论家具。住宅可沿“入口—公共前区—主要停留区—私密区—炊事区”看出入与安居是否有层次；办公室沿“到达—接待—共享通行—长时工位”看动区与静位；店铺沿“入店—浏览—候位—付款—离店”看前场承接和交易组织。只展开资料真实呈现的段落，不补画未见房间。

围绕这条主线论三组相互制约的关系：

| 关系 | 传统解释的落点 | 如何形成取舍 |
|---|---|---|
| 主与辅、动与静 | 主位是本次评估的长期使用核心；动静指活动与停留的关系 | 确定主位后再安排辅助物；能看入口不等于应坐在人流线上 |
| 靠与向、虚与实 | 室内“坐实向虚”类比背后稳定、面前可用；靠和向需一起成立 | 靠墙若造成面前逼塞，不能仅凭靠墙选为最佳；背窗也要看真实干扰与可控性 |
| 收与放、开与合 | 室内明堂、纳气是前区与内外连接的类比；聚不是把门窗封住 | 需要隐私时争取过渡，需要通行时保留通达；已有转折不机械增屏风 |

这里的“气路”若用于说明布局，应明确正在谈人的路线、视线、开口关系或待测风感，不能把四者画成同一股已测能量。最终总评应说明这些关系怎样共同支持保留现局，或哪一个关键冲突牵动全局，而非逐条累计煞名。

## 四、择取法：形势结论与理气结论各有依据

形势可以先成立自己的局部判断。若用户选理气，再按方法核边界、坐向、年代、时间层和盘面来源；不把形势意见假托为某一飞星组合，也不因为盘上用词吉利就略过实际门路。

| 方法层 | 这次需要回答的问题 | 应写明的区别 |
|---|---|---|
| 八宅宅卦、命卦 | 宅的分区、人与面向怎样按所选法门配合 | 宅卦与命卦不同；房间落宫与人面向不同；个人偏好不能代替多人总体布局 |
| 玄空飞星 | 宅盘如何建立，所论宫位叠的是哪一时间层 | 建成/入伙/换运取法、宅盘与流年流月分层；某数字相同不代表同盘同义 |
| 三合与水法 | 现场来去水、来龙及坐向怎样依指定法门比较 | 自然水系、排水设备和室内水景分别记录；不同罗盘层或水法不能互换 |
| 门主灶等阳宅法 | 版本中的对象在该建筑是否存在，现代如何对应 | 古院落主房、现代主卧、厨房门、炉头和操作面不能自动同义 |

需比较流派时，分别写清“作者/版本—对象—输入—结论层—行动”。方法相反且资料相同，保留分歧；先查对象或盘层不同造成的表面冲突。详见[方法比较](cases/method-comparison.md)，不在本文件补造排盘算法。

## 五、比方案：每一项改善都要说明代价

先比较保持现状、可撤回试摆和涉及工程的方案。按当前问题给优先顺序：如主要冲突在人流穿过长时座位，就先理顺这条关系；若现场使用已合理，只存在某一朝向偏好，可在同等可用的选项中争取。不存在所有住宅通用的一条“靠墙高于朝向”或“入口必先改”的绝对排序。

方案至少交代：保留的格局，拟动的对象与相对位置，预期改善的具体关系，会损失什么，以及如何复核。能用门扇完整开启、家具两态、实际坐位视点和使用体验比较时，先做这些复核；涉及边界、坐向、承重和管线的结论分别补资料。

现有多人斜桌原案（COMV7-001）的可学之处，是不能让每人的朝向偏好切碎共同使用空间；它并未证明一切斜桌都不利。因此报告可以主张先理顺共享路线，再比较可行桌向，而不把“桌斜”单独写成凶局。[商业专项及原文入口](cases/commercial-knowledge.md)

## 六、成文：先下有范围的判断，再给解释与动作

成文顺序建议为：整体判断与依据 → 决定性关系 → 条件相近案例的比较 → 优先方案及代价 → 会改变判断的关键缺项。纯知识问题可只保留相关原理与已有案例，不强求照片或生成新案例。

可采用这样的句式组织真实材料：“本次评的是〔对象〕。〔两项相互关联的证据〕说明现局以〔主线〕为核心；按〔明确取法〕，目前宜〔保留/调整〕。先做〔具体动作〕，因为它改善〔关系〕，同时要维持〔条件〕。若补充资料证实〔另一条件〕，再比较〔备选〕。”括号是写作提示，最终报告须填真实信息或删去，不能直接交付空模板。

这条流程要求呈现可复核的判断依据、传统解释和方案取舍；不要求输出模型内部推演或用“大师秘断”替代说明。语气可稳健明确，结论强度随资料而定。
