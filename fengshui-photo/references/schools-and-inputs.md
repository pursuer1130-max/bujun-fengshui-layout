# 流派选择与资料门槛

## 默认：形势及阳宅局部观察

从图里实际呈现的门窗、床、桌、灶、走道、外部道路和围合关系入手。可用传统的避直冲、求安定、重围护等概念作文化解读。单图可以做局部分析；无法把一间房推广为整栋楼的结论。明堂、龙虎、靠山等术语用于室内时说明是现代类比，不把建筑左右直接当罗盘东西。

| 用户所选体系 | 需要的资料 | 资料不足时 |
|---|---|---|
| 形势/峦头、阳宅可见布局 | 可看清主要物体及空间关系的图；若评外局需看到实际外部环境 | 仅分析所见范围，位置描述不用罗盘方位 |
| 八宅之宅卦 | 房屋或所评单元的完整边界、可靠坐向、立极对象、采用的取向口径 | 不定东四/西四宅，不把大门位置直接当房屋朝向 |
| 命卦及宅命配合 | 用户明确选择此法后，才讨论出生年、历法交界和传统算法所用性别字段；需指定算法及来源 | 不默认索取，不从照片/姓名推断；不把传统性别规则当个人价值评价；无可靠算法则解读用户提供的盘 |
| 玄空飞星宅盘 | 完整户型及立极、实测向首角度/坐向、磁北或真北说明、测量位置及误差、采用的建成/入伙/大修换运口径及年代、所用流派 | 不自动补年代，不把拍摄年份当宅运，不将当前运或某年飞星当已排出的宅盘；只解读可靠已有盘或先查方法 |
| 玄空流年/流月讨论 | 明确公历年份、立春/节气等交界口径、所用盘与实际方位 | 区分流年层与宅盘层，不靠年星独断某房的结果 |
| 三合、水法、二十四山分金 | 来龙去脉、来去水/水口、坐向的现场或可靠测绘资料、相应罗盘层及法门 | 外观照不能补出水口；不将鱼缸、排水管或走廊直接认作自然山水系统 |
| 阴宅/墓地照片 | 可见地形、墓区与开口视点；论坐向需明确碑面/墓体/墓穴对象与可靠测量，论精细选址还需现场地形水文 | 可作有范围的传统形势、格局与方案比较，按[阴宅专篇](yinzhai.md)写报告；不据单图精确定穴、分金、断后人命运或作迁葬决定 |

## 方位与尺寸

- 地理方位、建筑坐向、照片视线方向是不同量。图纸上的N只说明绘图标注的北向；若缺角度/精度，最多支持粗方向，不必然支持15度山向或兼向细分。
- 不默认户型图“上北下南”；若用户明确说了该约定，记为用户提供而非图中测得。图已旋转时按标注北箭头，不按纸面上下。
- 手机罗盘受金属、电器和测量位置影响。用户愿意补充时建议避开明显干扰，多点记录数值和方向，不承诺其精度。已知误差跨过分界时列为候选范围，不能四舍五入强定一山。
- 照片透视、广角、镜面和遮挡会改变线条关系。门窗在画面上近似同轴，不证明实际气流；具体风速、照度、距离需测量。没有标尺不报厘米。
- 多层住宅先明确评估整楼、单元、房间还是座位；不拿房间中心替代全宅中心。缺角、中心厕等判断须先说明边界和中心定义；小凹口、开放阳台和公共走道不能任意计入/剔除。

## 运算与合参

本包没有经过校验的命卦、飞星、分金计算器，不能装作已运行程序。用户提供可靠盘面时核对其输入、方向、年代、顺逆和图例再解释；需要重新排盘时先核实具体流派的原始规则及可靠工具，再展示输入与过程。不能凭熟悉的几个口诀补成完整盘。

用户未指定时保持形势主线。用户要求合参则逐项标明体系、适用条件、共同点和冲突，不以多数派投票得出概率，不把形峦九星与玄空飞星同名星号直接等同。不因用户说“要准”而提高断言强度。

这些是为图像工作流制定的资料门槛和审慎约定，不声称所有历史流派统一遵从同一套定义。古籍出处与争议须按 bibliography.md 和实际原文另核。
