# 看图与布局规则

需要结合已有记载解释格局和取舍时，选读[场景知识](cases/patterns.md)中的相关类别；要找原书或案例档案时转[资料入口](cases/recorded-sources.md)。当前文件用于可见空间观察，纯资料学习无需进入图片处理。

本文件是面向图像任务的原创分析规范。下列室内术语多为传统阳宅观念在现代居住环境中的通行表述，不预设出自某一部古书，不将其写成建筑科学定律。欲引用具体古籍，先查 bibliography.md，再读原段。实用建议的理由应能独立说明，不用古语替代测量和现场检查。需要了解本流程的学术参考及核验范围时，读 [研究依据](research-notes.md)。

## 一、图像与证据

| 输入 | 可以开始分析的内容 | 不能直接确定的内容 |
|---|---|---|
| 单张室内实景照片 | 主要可见物体、局部相对关系、明显遮挡、视线和通行的可能影响 | 全宅布局、被挡区域、真实门窗同轴、绝对方位、实际照度/风速/净宽、结构性质 |
| 完整户型图 | 标注的房间功能、门窗连接、图中几何关系与动线 | 实际入住摆设、实景采光、图中未写的朝向/年代、图纸是否准确 |
| 局部户型图 | 当前范围内的功能和位置 | 全宅中心、缺角、主入口位置、全宅财位 |
| 外观/街景照片 | 可见道路/建筑/围挡与入口的表观关系 | 室内布局、不可见道路延伸、车流噪声强度、地下水、整体来龙水口 |
| 效果图、AI图或样板间 | 该设计画面所呈现的布局 | 实景已建成、墙体用途、真实景观或可施工性 |

图中明显手写标记是用户资料；如与可见图形冲突，指出冲突，不静默挑一个。模糊标注先说无法辨认；不能把猜出来的数字当尺寸。图中含私人信息时不复述无关姓名、门牌或账号。

内部可建立这样的证据记录，用户不必填写：

```text
F1 画面右侧：沙发背后可见一段实墙。可见事实，高。
F2 画面左下：门扇旁有高柜，通道可能变窄。空间推断，中；未测净宽。
U1 入口后方区域未入镜；全宅结构、方位、窗外环境未知。
```

不要因图中有床就认定为卧室实景，不因窗外植物就认定住宅临山，不因窗户大就断定采光充足。可表述“画面中较亮，但拍摄曝光会影响判断”。镜中反射的门/窗不是新增一扇门/窗；同一家具被反射不重复计数。

## 二、按场景选择规则

### 入口、门窗与通道

- **门窗直冲/穿堂（传统阳宅说法）**：先看是否为同一空间的真实开口、视线是否连通、门窗是否实际同时开启。透视图中“似乎对齐”只列待核。现实讨论集中在隐私、穿行、风感与遮挡，不能由此推“漏财”。调整可为可移家具或适量遮帘，但要保留通行和通风。
- **门口拥堵**：指出看得到的柜、鞋或杂物及可能影响的路线。无尺寸只说可能影响通行；不编具体净宽或法规数值。
- **门对门/厕门**：能确认房间功能与真实视线才分析。关注私密、门扇碰撞、日常使用；气味与湿度没有现场依据时不能说已存在。可先讨论门的使用、清洁、遮挡需求，不把关门代替必要换气。

### 床与卧室

- **床头有靠（通行传统偏好）**：可见床头靠实墙可作为稳定感的空间特点；不能据照片确认其结构或隔声。床头靠窗并非自动定凶，进一步看真实风感、遮光、窗帘和使用偏好。建议先调遮光或位置，不一概封窗。
- **床门关系**：区分床与门在画面上的投影、实际通行路线、躺下是否看得到门。传统避直冲可转化为睡眠私密与减少干扰的偏好，不断疾病或婚姻。
- **梁压床/吊顶**：照片只见凸出构件时可说“疑似梁或吊顶”；不从外形断承重。传统压迫感属解释。可讨论视觉压迫、眩光或换位；不得建议削梁、拆墙、在床上方挂重装饰。
- **镜子照床**：须确认镜面与反射方向。可讨论夜间反射、个人舒适与隐私；不能说一定招灵或影响关系。若用户不介意且无实际问题，无需强行移动。

### 客厅、书房与办公室

- **座位背靠/看门（通行传统偏好）**：先确认靠背后是实墙、窗、走道还是画面盲区；视野与背后通行是否造成干扰可以讨论。“靠山”作室内比喻时明说是类比。
- **沙发、桌椅与通道**：移动前核对开门、拉椅、进出的可用空间；未知尺寸则给条件式建议。不要为了形式上的背靠牺牲逃生路线。
- **可变家具与兼用房**：沙发床、折叠桌及抽拉柜同时检查收起与展开状态；现图未显示的展开空间保持待核。办公兼客房先核客床、拉椅与必经路是否冲突，具体方法见 [案例新增规则](cases/learning.md)。
- **照明、屏幕和窗**：仅凭画面可提出检查眩光、反射或遮挡的建议，不能报告未测照度。实用建议依照用户工作习惯和实际体验。
- **财位/文昌位**：不默认把大门对角命名为全流派通用财位。用户专问时说明民俗取法多种；采用“明财位”等通行约定要标明具体取法与不确定性，不据此承诺财富或学业表现。

### 厨房与卫生间

- **水火关系**：水槽与灶邻近/相对是几何事实；五行水火是传统解释。不能把颜色、冰箱或洗衣机自动当同等“水”或“火”。实用建议着眼操作台、热源、溅水、清洁及真实使用状况；安全间距按设备说明和现场条件核实，不从无尺度图片报数。
- **灶位/灶向**：灶的位置、使用者站位、火门/旋钮方向、住宅坐向不是同一量。用户未选择具体取法时不用其中一项替代另一项；电磁炉等现代设备的类比要说明。
- **中心厕/湿区**：必须有全宅边界和中心定义。单间浴室照片不能推出“厕居中宫”。现实关注通风、防水、潮湿等是否有实际证据；不要据斑点照片诊断霉菌或疾病。

### 外部道路、建筑和山水

商铺或公共空间有多扇门时，先确认顾客、送货、内部连接及应急用途，再分析实际路线；不以照片正面或门的大小自动认主入口。圆楼、围院、古版鸟瞰及城市图先确定尺度和投影，不把庭院空白当普通房间缺角，也不从古图像素测量真实通道。

- **路冲/角冲/反弓（传统形势术语）**：需要可见对象与入口或窗的真实位置关系；若只有一个远处尖角或道路局部，列条件不足。现实层可提出核实灯光、车流、视线和噪声，不将箭头、阴影或装饰线误认道路。
- **山、水、围合与开敞**：表述图中实际地形/水体；不把河流、水景、雨水沟、鱼缸、车道混成同一术法对象。照片无法完成地质、水文、洪涝或风环境勘测。
- **龙虎/靠山/明堂**：说明所采用观察基点与朝向口径；未知时只用左/右/前/后。不能把建筑周围的每个物体强配四兽。

## 三、建议的优先顺序

1. 若确有明显可见的现实障碍或危险线索，先提出可撤回的整理/核实建议；仅有疑点则说“需要现场确认”。
2. 改善用户实际体验：路线、隐私、遮光、座位视野、收纳与使用便利。先说明目的，再给动作。
3. 传统形式偏好：在不妨碍功能的前提下提供可选布置。尺寸不足时提供A/B条件方案，不给虚构精度。
4. 无需改动的部分明确保留；不要默认购买屏风、法器、水晶、鱼缸或摆件。用户已有装饰偏好可以尊重，但不把物件当保证改运工具。

## 四、把观察写成专业报告

完成上述观察后，按 [专业报告写作规范](professional-report.md) 组织成篇：先给整体格局与处理方向，解释关键空间关系及取法，再提出保留/调整/待核的方案，最后集中说明结论边界。物件清单和逐格套术语只能作内部记录，不能替代布局论证。

标题、栏目和篇幅依图片信息及用户要求调整。简单图片也应有清楚的取舍理由，不凑空表、煞名、分数或章节。用户要JSON时可沿用 `scope / observations / interpretations / actions / unknowns / sources`，每个解释关联观察编号；未知字段用 null，不补造数据。
