# 卜君风水布局：使用与安装

## 本包内容及适用范围

现支持阳宅与阴宅两个专篇。直接读书时从[阳宅](../references/yangzhai.md)或[阴宅](../references/yinzhai.md)进入实际篇章研读与取法；看图时按两类对象选择流程与报告，不把墓地分析写成家具禁忌清单。现行既有案例目标为不少于100,000例，尚未完成，详见[进度](../references/cases/corpus-progress.md)。

`fengshui-photo`（卜君风水布局）由标准 SKILL.md、按需读取的分析规范、带来源的书目与有限古籍资料、独立的通用提示词构成。品牌名已经更新，技术标识和 `$fengshui-photo` 调用名保持兼容。不是对 AI 的模型权重训练，也没有自动飞星/命卦排盘引擎。它支持单张照片先做局部分析；一张图通常不能提供全宅朝向、年代、比例、遮挡区域及外部山水等信息。

资料范围、实际已存文本数量与核验程度以 `references/bibliography.md`、`references/classics/index.md` 和 `references/classics/manifest.json` 为准。未声称集齐所有风水书。现代著作只列合法书目或来源链接，不随包复制整本。

2026-10-27加入[既有案例与文献入口](../references/cases/recorded-sources.md)和[16类场景知识](../references/cases/patterns.md)：17条案例集/版本书目、11个网上档案/栏目及5项研究来源。书目、目录、正文与图像核验层级分别保留。已有37个具体案例的原创短笔记供离线检索，这个数量不代表外部资料规模，也不要求重新处理一万张图来丰富技能。资料整合不是底层模型权重训练。

专业书写更新：照片分析默认形成有整体判断、方法依据、布局取舍及实施次序的报告。术语随用随释，说明室内类比与适用条件；正文以连贯论证为主，表格用于辅助比较。写作标准见 [专业报告规范](../references/professional-report.md)。

笔画标注更新：在实际看图任务中默认同时制作并显示带编号、引线、圈线和中文图例的照片标注图，报告与图中编号对应。用户仅要文字时除外；无适用工具则说明图像未处理，不以原图链接或文字冒充成品。方法与交付要求见 [照片标注规范](../references/photo-annotation.md)。

## 在 Codex 使用

安装后可直接提出资料或知识问题，例如：

```text
使用 $fengshui-photo，从已有记载中解释门、主、灶的取法差异，并丰富相关知识。无需处理照片。
```

需要看图时，再附图并说：

```text
使用 $fengshui-photo 分析这张图片中的风水布局，并给出可执行的调整建议。
```

普通“帮我看风水”的请求也可以触发自动选择；已建立风水分析上下文时，继续发图即可。具体是否选择由运行环境决定。查找不到时可明确写出技能名。

官方文档列出的用户技能目录是 `~/.agents/skills/`。完整技能目录安装为 `~/.agents/skills/fengshui-photo/`，其中直接包含 SKILL.md。Codex 可自动发现新增技能；若列表未更新，重启 Codex。不要在多个发现目录重复安装同名技能，也不需要为此改全局安全配置。

如运行环境没有自动发现，也可要求“读取所附技能目录中的 SKILL.md 并按其执行”。本包不替其他应用注册插件或修改其配置。

依据：[OpenAI 官方 Build skills 文档](https://learn.chatgpt.com/docs/build-skills)，核验日期 2026-10-25。

## 其他 AI

- 支持 Agent Skills 的工具：按目标平台说明导入整个 `fengshui-photo` 文件夹；平台可能有不同目录或上传限制。
- 只有对话框/自定义指令的工具：复制 `portable/通用风水看图提示词.md`，再发图；要引用古籍时另附书目和相关正文。
- 没有视觉能力的工具：提供房间功能、门窗、家具相对位置的文字描述。无文件工具时不能自动读取本地书库，无联网工具时不能声称检索到在线原文。

本包的核心中文指令不依赖某家模型的 API 或运行时；“可移植”不等于每个 AI 都支持自动导入或看图。

## 合适的输入

最便捷：一张尽量清楚、能呈现主要门窗与家具关系的照片，或一张完整户型图。图片上可以先遮掉姓名、门牌和地址。补充朝向、尺寸或年代是为了指定流派的后续分析，普通单图流程并不强制提供这些资料。

如需玄空等精细讨论，应补充分界明确的户型、实测朝向和误差、建成/入伙/重大装修时间及取法。未知就保留未知，不能用当前年份或拍摄时间补齐。

## 外局与商业条件的进一步使用

2026-10-29增加[外局专项](../references/cases/exterior-knowledge.md)与[商业专项](../references/cases/commercial-knowledge.md)：12组原作者/机构的指定正文材料，含实践自述、项目评述、来电问答、身份未明简例及明确教学，未把它们合称12份核验咨询报告。另有[六项方法比较](../references/cases/method-comparison.md)解释取向、门主灶、镜面、盘层和边界等分歧，具体来源与未核范围随文件保存。

案例的用途是形成条件与取舍，例如邻楼角先核实际楼层和目标开口；收银分清位置、操作者面向、客户站位及队列；多人朝向偏好不能切碎共享路线。此轮未处理照片，也未新增数字排盘算法。原本地短笔记账本仍独立维护，专项文字材料按其链接读取。

“风水师角度”的整体判断使用[格局研判](../references/layout-assessment.md)，按对象、尺度、外局、内局、取法和方案组织。现行目标为不少于100,000个已有案例，[进度说明](../references/cases/corpus-progress.md)列明已读材料与未完成事项，未以数据集条目或经验宣传补数。
